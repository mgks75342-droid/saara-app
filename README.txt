Saara App v4 (GitHub Actions দিয়ে APK বানানো)

ধাপ ১: GitHub repository-তে এই ZIP-এর সব ফাইল আপলোড করুন (পুরনোটা ওভাররাইট)।
ধাপ ২: Actions → Build Saara APK → Run workflow। Artifacts থেকে APK ডাউনলোড করুন।
ধাপ ৩: APK ইনস্টল করে অ্যাপ খুলুন।
ধাপ ৪: "অ্যাক্সেসিবিলিটি" বোতাম → Saara চালু করুন (স্ক্রিন পড়ার জন্য)।
ধাপ ৫: "Gemini key" বোতামে নিজের key বসান।

কী করা যাবে (লিখে বলুন):
- যেকোনো প্রশ্ন: উত্তর দেবে (Gemini)
- "ইউটিউবে <বিষয়> সার্চ করো": ইউটিউব খুলে সার্চ করবে, পেলে জিজ্ঞেস করবে দেখতে চান কিনা। "হ্যাঁ" বললে প্রথম ভিডিওটা খুলবে।
- "স্ক্রিনে কী হয়েছে": এখন স্ক্রিনে কী আছে তা বলবে।
- "কোড দেখো / সমস্যা আছে কিনা": স্ক্রিনের কোড বা পেস্ট করা কোড দেখে সমস্যা বলবে।
- "<অ্যাপ> খোলো", "সময় কত", "তারিখ", "<ফাইল> ডিলিট করো" (ডাউনলোড ফোল্ডার)।

মাইক: উপরে "🎤 মাইক" বোতামে একবার চাপলে নিজে থেকে শুনতে থাকবে, আবার চাপলে বন্ধ। প্রথমবার মাইকের অনুমতি দিন।
Google Speech সার্ভিস ফোনে চালু থাকতে হবে (বাংলা না পেলে ইংরেজি/হিন্দিতে কাজ করবে)।
