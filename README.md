# Sara - Android App (features)

- Reference UI (app/assets/index.html + bg.jpg)
- Microphone / Gemini Live (app/assets/mic.js)
- Accessibility setting shortcut and screen text reading
- Notification reading (after Notification Access is granted)
- File manager: list, create, delete (with confirmation)

Permissions are granted by the user in Android settings.
Build: GitHub > Actions > Build APK > Run workflow > download Sara-APK.
