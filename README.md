# Sara AI - Android App

- app/assets/index.html : Sara home UI (matches the reference design)
- app/assets/mic.js     : Microphone / Gemini Live voice module
- app/src/com/sara/app/MainActivity.java : WebView wrapper
- app/AndroidManifest.xml
- .github/workflows/build.yml : GitHub Actions APK build

Build: GitHub > Actions > Build APK > Run workflow > download Sara-APK.
